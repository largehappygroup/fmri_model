This repo contains code for training voxelwise encoding models of fMRI data using participants' keystrokes during a code/prose writing experiment.

The folder `replication_package` contains the analysis code organized step-by-step, but all the original code is in `analysis/fir`. 

The fMRI files are too large for github, but sample data from five participants can be found [here]{https://vanderbilt365-my.sharepoint.com/:f:/g/personal/z_karas_vanderbilt_edu/IgD3VactGhJgQJZMhB3h0ewIAbQpN-zDFcGbyhfl00ns4fM?e=Cm5G7Y}.
